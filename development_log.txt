Key Decisions
Decision 1: Move Department to Employees App

Reason: Departments manage employees, not organizations

Benefit: Cleaner domain boundaries, fewer circular deps

Trade-off: Migration complexity (worth it for long-term maintainability)

Decision 2: Manual SQL for Schema Changes

Reason: Avoid migration conflicts after faking

Benefit: Direct control over database state

Trade-off: Not trackable in migrations (documented in dev log)

Decision 3: Remove Obsolete Fields

Reason: Simplify model, improve performance

Benefit: Cleaner codebase, faster queries

Trade-off: Data loss (acceptable for development phase)
