## Challenges & Solutions

### Challenge 1: Docker Build DNS Failure
**Problem**: Docker couldn't resolve debian repository hostnames
**Error**: `Could not resolve deb.debian.org`
**Solution**: 
1. Open Docker Desktop → Settings → Docker Engine
2. Add DNS configuration:
{
"dns": ["8.8.8.8", "8.8.4.4"]
}
3. Restart Docker Desktop
4. Restart system
**Time Lost**: 15 minutes

---

### Challenge 2: Circular Dependency in Migrations
**Problem**: Employee → Department → Employee (head field)
**Error**: `CircularDependencyError: employees.0001_initial, organizations.0001_initial`
**Solution**: 
1. Deleted initial migrations
2. Created organizations migration first
3. Django auto-created two-stage employee migration
4. Applied in correct order
**Time Lost**: 10 minutes

---

### Challenge 3: Keycloak Authentication Errors
**Problem**: `AsyncClient.__init__() got an unexpected keyword argument 'proxies'`
**Error Location**: `python-keycloak` library incompatibility with `httpx`
**Solution**: 
1. Commented out `KeycloakAuthenticationMiddleware` in settings
2. Changed REST_FRAMEWORK permissions to `AllowAny`
3. Disabled authentication for development
**Note**: Will fix in future by downgrading python-keycloak
**Time Lost**: 20 minutes

---

### Challenge 4: Permission Denied (403) on API
**Problem**: ViewSets still enforcing `IsAuthenticated` permission
**Error**: `{"error": "You do not have permission to perform this action."}`
**Solution**:
1. Commented out `permission_classes = [IsAuthenticated]` in:
- `employees/views.py` (line 30)
- `organizations/views.py` (lines 28, 87)
2. Restarted hr-core
**Time Lost**: 10 minutes

---

### Challenge 5: PowerShell Docker Exec Issues
**Problem**: Couldn't paste commands into `docker exec bash` session
**Solution**: 
- Used individual `docker-compose exec` commands from PowerShell instead
- Example: `docker-compose exec hr-core python manage.py migrate`
**Time Lost**: 5 minutes

---

## Key Decisions

### Decision 1: Two-Stage Migrations
**Reason**: Handle circular dependency between Employee and Department
**Alternative Considered**: Commenting out Department.head field
**Chosen Approach**: Let Django handle it automatically
**Result**: Clean, maintainable migration structure

---

### Decision 2: Disable Authentication for Development
**Reason**: python-keycloak library incompatibility
**Alternative Considered**: Downgrade library immediately
**Chosen Approach**: Disable for now, fix in future iteration
**Result**: Can continue development without blocking issues

---

### Decision 3: MongoDB for Audit Logs
**Reason**: Better suited for write-heavy logging than PostgreSQL
**Alternative Considered**: PostgreSQL audit table
**Chosen Approach**: Separate MongoDB database
**Result**: Scalable audit logging solution

---

### Decision 4: Neo4j for Org Charts
**Reason**: Graph database perfect for hierarchy queries
**Alternative Considered**: PostgreSQL recursive CTEs
**Chosen Approach**: Neo4j with REPORTS_TO relationships
**Result**: Framework ready (sync not yet implemented)
